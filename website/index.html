What exactly is TeleRAG?

TeleRAG is a document-to-Telegram chatbot project for small businesses. The idea is simple: use your existing business documents to help answer customer questions in Telegram. RAG means retrieval-augmented generation — finding relevant source material before writing an answer.

Is the full system ready to use?

The project currently contains the Appwrite resource setup and shared data model. Document ingestion, live Telegram bots, and the business dashboard are planned for later milestones. This website includes an interactive local demo so you can explore the experience now.

Do I need Supabase to try this?

No. This website and its scripted demo run without Supabase, Appwrite, API keys, or an internet connection once served locally. The backend setup in this repository uses Appwrite; the website does not call it.

What kinds of documents are supported?

The backend storage configuration accepts PDF, DOCX, XLSX, CSV, TXT, Markdown, PNG, JPEG, and WebP, up to 10 MiB per file. Live ingestion and answering from uploaded files are planned features; the demo uses three built-in sample documents.

Can I try it with my own documents here?

This preview uses the fictional Sunday Studio’s sample content. Uploading and processing your own documents will be part of the full application, once ingestion and bot services are connected.
